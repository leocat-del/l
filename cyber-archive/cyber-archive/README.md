# CYBER ARCHIVE

Секретный цифровой архив: React + Vite. Весь текст лежит в `src/data/archive.js`.

## Выложить на GitHub Pages

1. Создайте репозиторий на GitHub и загрузите в него **содержимое** этой папки (Add file → Upload files). Папка `.github` скрытая, её нужно загрузить тоже.
2. В репозитории: Settings → Pages → Source: **GitHub Actions**.
3. Сделайте любой коммит в ветку `main` или запустите «Deploy to GitHub Pages» вручную во вкладке Actions.
4. Через минуту-две сайт откроется по адресу `https://ВАШ-НИК.github.io/НАЗВАНИЕ-РЕПОЗИТОРИЯ/`.

Адрес `/signal` работает и при прямом открытии: при сборке создаётся `404.html`, которую GitHub Pages отдаёт для неизвестных адресов.

## Вставить картинки через GitHub

Откройте в репозитории папку `public/images`, нажмите Add file → Upload files и загрузите файлы с такими именами:

- `image-1.jpg`, `image-2.jpg`, `image-3.jpg`, `image-4.jpg` (вкладка VISUAL EVIDENCE)
- `secret-image.jpg` (страница `/signal`)

Расширения `.jpg`, `.jpeg`, `.png`, `.webp`, `.avif` подхватываются автоматически. После коммита сайт пересоберётся сам. Пока файла нет, показывается заглушка.

## Секрет

Пять быстрых кликов (за 3 секунды) по маленькой пульсирующей точке справа от слова ACTIVE в шапке. Напрямую: `/signal`. Выход: Escape или надпись ESC в углу.

## Изменить текст

Документы и разделы правятся в `src/data/archive.js`. Типы блоков: `p` (абзац), `h` (подзаголовок), `ul` (список), `restricted` (тёмный засекреченный блок, он автоматически попадает и во вкладку RESTRICTED), `empty` (пустая запись). Новый документ добавляется новым объектом в массив `documents`.

## Локальный запуск

```
npm install
npm run dev
```

Netlify: уже есть `public/_redirects`. nginx: `try_files $uri /index.html;`.
